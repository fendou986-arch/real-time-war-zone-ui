# 战区脉搏 · 实时战争热区态势界面

> 一个面向开放情报可视化场景的深色态势感知仪表盘，用地图、热区脉冲、事件时间轴和实时活动列表，将复杂的区域安全信息转化为清晰、直观、可操作的视觉体验。

[在线查看 GitHub 项目](https://github.com/fendou986-arch/real-time-war-zone-ui)

## 项目简介

**战区脉搏**是一款以“实时战争热区”为主题打造的单页可视化界面原型。

它借鉴情报中心、应急指挥中心和安全运营中心的交互语言，通过深色背景、青绿色数据层、橙红色风险标记和脉冲动画，营造出具有专业感和临场感的实时监测体验。

页面聚焦于一个核心问题：

> 如何让用户在几秒钟内理解当前区域的风险分布、事件强度和最新活动？

答案被拆解为地图态势、热点等级、事件摘要和时间变化四个层次，让信息既有全局视角，也保留足够的细节入口。

## 核心亮点

### 1. 中央战区态势地图

- 采用示意地图呈现东欧与黑海区域
- 通过网格、河流、边界线和地名构建空间层次
- 不同颜色代表不同级别的活动信号
- 热点标记支持脉冲动画和悬停详情
- 提供放大、缩小和定位交互

### 2. 风险等级可视化

系统使用三种颜色表达事件强度：

- **红色：高强度冲突**
- **橙色：军事活动**
- **黄色：紧张事件**

颜色、光晕和动态扩散共同构成易于识别的风险语言，帮助用户快速定位最值得关注的区域。

### 3. 实时态势概览

右侧信息面板集中展示关键指标：

- 当前活跃热点数量
- 过去 24 小时事件总量
- 受影响区域数量
- 信息置信度

数据以卡片形式呈现，适合在大屏、监控台和桌面端快速浏览。

### 4. 最新活动列表

活动列表按照时间顺序展示近期事件，包括：

- 事件发生区域
- 活动类型
- 信号来源
- 事件强度
- 距离当前时间

通过“刚刚、02 分钟前、08 分钟前”等相对时间，强化实时监控的节奏感。

### 5. 24 小时时间轴

底部时间轴用于观察过去一天内的活动分布：

- 标记关键事件发生时间
- 高强度事件使用红色强调
- 普通活动使用橙色标记
- 当前窗口以绿色轨道表示

它可以帮助用户从单点事件进一步理解活动的时间趋势。

### 6. 数据图层与筛选

左侧控制面板提供：

- 全球态势、欧洲东部、中东地区、非洲之角、亚太区域视图
- 事件强度滑块筛选
- 卫星图像、新闻情报、社交信号来源状态
- 风险图例和图层说明

## 交互体验

当前页面内置了轻量级交互逻辑：

- 点击“刷新数据”会更新时间并显示更新反馈
- 活跃热点数量会自动模拟刷新
- 拖动事件强度滑块会实时更新筛选数值
- 点击“图层管理”会切换激活状态
- 地图支持放大、缩小和定位
- 鼠标悬停在热点上可以查看区域活动说明

## 技术特点

- 原生 HTML、CSS、JavaScript

- 响应式布局适配桌面端窗口
- CSS 绘制地图背景、网格、边界和热点效果
- 无第三方运行时依赖


## 数据说明

当前版本使用的是**演示用模拟数据**，用于展示界面结构、视觉层级和交互效果，并不代表真实战况，也不应被用于现实世界的决策、报道或风险判断。

如果用于真实项目，可以接入：

- 经过验证的新闻事件 API
- 卫星图像与遥感分析服务
- 地理空间数据与地图瓦片服务
- 多源事件聚合和去重系统
- 权威机构发布的安全态势数据

接入真实数据时，应增加数据来源标注、时间戳、置信度、交叉验证和隐私安全机制。
